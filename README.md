# DR-TECANY | دكتور تقني 💻⚡

صفحة هبوط (Landing Page) احترافية وتفاعلية لمركز **دكتور تقني (DR TECANY)** المتخصص في صيانة وإصلاح وترقية أجهزة اللابتوب.

## المميزات والأقسام
- **تصميم UI/UX عصري ومتجاوب (Responsive)**: يعمل بكفاءة على الموبايل، التابلت، وأجهزة الكمبيوتر.
- **المشخّص الذكي للأعطال**: أداة تفاعلية لتشخيص عطل الجهاز واقتراح الخدمة المناسبة فوراً.
- **قسم الخدمات المتكامل**: صيانة الهاردوير والماذربورد، تثبيت ويندوز وبرامج، إزالة الفيروسات، تحسين الأداء والتبريد، وترقية RAM و SSD.
- **باقات الصيانة والأسعار**: مع محول عملات تفاعلي (جنيه مصري / ريال سعودي / دولار).
- **نبذة عن المركز وفريق العمل**: خطوات الصيانة وبطاقات تعريف المهندسين.
- **آراء العملاء السابقين**: مع فلترة تفاعلية حسب نوع الخدمة.
- **نموذج حجز وتواصل نشط**: مع التحقق الذكي وإصدار تذكرة حجز فورية وإمكانية الإرسال عبر واتساب.

## التقنيات المستخدمة
- HTML5 (Semantic RTL)
- CSS3 (Custom Properties, Grid, Flexbox, Glassmorphism)
- Vanilla JavaScript (ES6+)
